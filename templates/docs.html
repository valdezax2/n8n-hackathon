Using it from n8n (HTTP Request node)

URL to use: n8n running in Docker cannot reach localhost on your Mac — use http://host.docker.internal:5050. n8n running natively (npx/desktop) can use http://localhost:5050. n8n Cloud needs a public tunnel (e.g. ngrok http 5050).

Look up a caller by phone — Method GET, URL:

http://host.docker.internal:5050/api/contacts?phone={{ '{{ $json.phone }}' }}

Log a conversation — Method POST, Body Content Type JSON, URL /api/contacts/1/conversations:

{"channel": "Phone", "subject": "AI call", "summary": "Customer asked about renewal pricing.", "sentiment": "positive", "rep": "n8n bot"}

curl test:

curl {{ base }}/api/contacts?limit=2&include_conversations=false
